Follow-up to the DataObject TKVL: a RandomAccessReedSolomon-specialized, append-based DataObject node
encoding. Rather than a full overwrite on every kv insert/delete, append operations insert kv pairs
and tombstones until the object is full. If compaction frees up enough space, the object can be
overwritten and append operations can resume until a split is eventually required. The encoding is a
pluggable NodeEncoding so it plugs in without touching the tree logic in TierEngine.
  - Note that appending to the object saves write bandwidth but comes at the cost of increasing read
    bandwidth.
    - The implementation should balance the two. Rather than blindly appending, calculate the cost
      of doing a subsequent read when choosing to append or a compacted overwrite. There probably
      isn't a single solution that is ideal in all cases. If possible, design the code such that
      a plugin (or just a callback) can be provided that optimize to specific use cases but default to
      a good, general-purpose implementation.

Need a mechanism to handle "out of space" errors
  - Will present when we attempt to commit an object update to the store
    - Read-Only or out of space underlying media will cause it to fail
  - Will clog up the CRL if left untreated
  - Might start with just relying on TransferStore to a device with space
    - Might be able to automate this eventually
  - Could set up "spillover stores"
    - Dedicated to hosting data for full stores
    - Lots of implications though, will require some thought

For maximum recovery speed, DurableRecoveryManagerTask
  - Delegates restore operations to groups of workers
  - Workers restore objects
     - Store the results locally (not re-erasure coded)
       - Could use a RocksDB-like backend. Key = ObjId + PoolIndex
     - Update dist datastructure noting their location
  - End-location downloads rebulit slices as they're created

  + End-location can be throttled so as not to overload bandwidth
  + Data can be rebuilt at maximum speed (no choke points)
  + Rebuilt data can be read from dist data structure at a speed penalty
